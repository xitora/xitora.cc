# 3. 직접 우회
## 준비물
- 해외 결제가 가능한 신용/체크카드 (VISA, Master 등)

## 진행 방법

### 1. 신규 가입자
1. [**한국 공식 홈페이지**](https://spotify.com) 에서 일반 회원가입 및 로그인
2. 우측 상단 메뉴 → 프리미엄 → 시작하기 클릭
3. 결제 화면에서 **국가 변경** 클릭 후, **일본** 선택 `(일본 요금제로 변경됨)`
4. **PayPal(페이팔)** 선택 후 **구매 계속하기** 클릭
5. 페이팔 가입 및 카드 등록 (핵심):
    - 페이팔에서 계정 생성(アカウントの作成)을 눌러 가입 진행 후 카드 등록.
    - ⚠️ 페이팔 사이트에서 직접 가입 시 전화번호 인증이 필요하지만, 스포티파이 결제 창을 통하여 가입하면 전화번호 인증을 건너뛸 수 있음
6. 스포티파이로 돌아와 등록한 페이팔로 최종 결제 진행

### 2. 기존 가입자
1. 스포티파이 **계정 페이지** 접속
2. 요금제 정보 영역에서 **업데이트하기** 클릭
3. 동일하게 국가를 **일본** 으로 변경
4. 위와 동일한 페이팔 결제 방식으로 진행하면, 다음 결제 주기부터 일본 스포티파이로 자동 전환됨

# 6. Spicetify를 통한 데스크탑 이용
>`⚠️ 주의: 자주 막힐 수 있으며, 주기적인 패치 업데이트 필요.`

- 윈도우 11 기준, 시작 버튼 로고에 우클릭 > 터미널 (관리자 권한 X)
    - 혹은 powershell 실행

아래 명령어 입력
```powershell
iwr -useb https://raw.githubusercontent.com/spicetify/cli/main/install.ps1 | iex
```
응답 요청이 보이면 <kbd>Y</kbd> 입력 후 엔터

설치가 완료되었다면 바로 다음 명령어 입력
```powershell
iwr -useb https://raw.githubusercontent.com/spicetify/marketplace/main/resources/install.ps1 | iex
```


스포티파이 실행 후, 좌측 상탄에 카트 모양 아이콘(`이하 마켓플레이스`)이 표시된다면 성공

마켓플레이스로 이동 후 **확장 프로그램 카테고리**에서 **adblockify** 설치 후 재시작

이후로부터는 광고가 표시되지 않음
